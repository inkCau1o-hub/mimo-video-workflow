# 第一阶段编辑契约

本文件是实施约定，不表示功能已经验收。

## 镜头

沿用 `StoryboardShot`，新配置写在 `metadata.edit`，不改动原 `metadata.material_asset_id`。

```json
{
  "source_in": 0,
  "source_out": null,
  "fit": "cover",
  "crop_x": 0.5,
  "crop_y": 0.5,
  "shortage": "freeze",
  "duration_mode": "narration",
  "subtitle": {
    "text": "独立字幕，可包含换行；空字符串表示关闭该镜头字幕",
    "position": "bottom",
    "font_size": 48,
    "color": "#FFFFFF",
    "background": false
  }
}
```

- 不含 edit 的旧项目保留原默认行为。缺少 subtitle.text 时回退到 tts_text 或 script_text，显式空字符串不回退。
- source_in >= 0；source_out 为 null 或大于 source_in；明确选择的范围不得超出已知素材时长。自动匹配时也必须在渲染前依据实际媒体校验。
- fit 为 cover/contain；crop_x/crop_y 在 0..1，代表缩放后可裁剪区域的位置。contain 忽略裁剪坐标，居中留黑边。
- shortage 为 freeze/error。选段比目标时长短时，freeze 补末帧并提示，error 拒绝；不得偷偷循环或截断旁白。
- duration_mode 为 narration/manual。默认按实测配音时长，manual 按镜头 duration_seconds；manual 不允许短于现有配音。没有配音时沿用镜头时长。
- subtitle.position 为 top/center/bottom；font_size 为 16..96（720p 画布基准）；color 为 #RRGGBB；background 为布尔值。字幕样式不能作为 FFmpeg/ASS 指令注入。
- 前端复制镜头使用新的稳定 ID，metadata.duplicate_of 保存来源镜头 ID；后端仅当原镜头仍存在且旁白一致时复用音频，生成新的 segment_id，但不复制媒体文件。
- 顺序就是 shots 数组顺序；删除最后一个镜头不允许。字幕、裁剪和顺序变化不清除有效配音；配音正文改变只清除对应音频。

## 历史 API

- GET /projects/{id}/editor/history 返回 `{history: {cursor, can_undo, can_redo, entries: [{id, label, created_at}]}}`。
- POST /projects/{id}/editor/history：`{activity_id, action: undo|redo|restore|checkpoint, revision_id?, label?, base_revision?}`；返回项目 payload 和上述 history。
- POST /projects/{id}/storyboard/shots 保持原接口，增加可选 label/base_revision，返回项目 payload 和 history。
- base_revision 若提供，必须与当前历史条目 id 一致；无历史时为 ""。冲突应提示刷新，不能覆盖另一份修改。
- 每次保存前记录现态，保存后记录新态。历史最多 30 条，包含镜头及其配音引用，不复制媒体、不递归保存历史。
- 撤销/重做在保存的历史上移动；从旧版本恢复生成新的版本，保留原历史。撤销后新编辑按通常规则截断 redo 分支，已生成文件和 exports 列表不删除。
- 恢复镜头时同步恢复当时配音引用，重新生成合成计划；旧成片始终保留在 exports，不能冒充当前编辑结果。
- 草稿内撤销/重做由界面实现；有未保存内容时禁止恢复已保存版本，避免静默丢弃草稿。
- 历史随项目保存，媒体路径继续遵循现有相对路径序列化。保存失败必须回滚内存状态。

## 阶段二扩展：字幕时间与前后留白

- `metadata.edit.lead_in_seconds`、`tail_out_seconds` 为 0..10 秒，缺省为 0；缺省字段不强行写入旧项目。
- narration 模式：镜头总时长为实测配音 + 前留白 + 后留白；manual 模式：总时长仍取镜头时长，但不得小于三者之和。没有配音时沿用镜头时长，前后留白之和必须小于镜头时长。完整配音保留，不剪掉语句内部停顿。
- `subtitle.timing_mode` 支持 `full`（默认，整镜头）、`narration`（配音期间）、`cues`（逐条定时）。没有配音时 narration 字幕使用镜头去除前后留白的区间。
- `subtitle.cues` 为最多 100 条 `{start, end, text}`；单位为秒，相对当前镜头起点。按时间排序、不得重叠、每条至少 0.01 秒，正文非空且总计不超过一万字；允许条目之间留空。
- cues 模式只显示 cues，不回退到 subtitle.text；空数组表示本镜头不显示字幕。其他模式保留但不使用 cues；仍检查其基本结构，只有使用时检查是否越过镜头总时长。
- 保存依据已知配音时长检查，正式导出再次依据实测媒体检查；配音更新导致字幕越界时拒绝导出，不静默截断字幕。
- `subtitle.timing_source` 为 manual/estimated。估算分句按正文长度分配时间，不是语音识别或强制对齐；用户显式确认校准前，在界面和导出警告中保留估算标记。
- 前后留白使用静音补齐；字幕按对应事件烧录；最终视频时长仍按帧率向上对齐。合成结果保存每镜头实际时长与字幕事件用于核对。
- 字幕批量纠词先显示逐镜头变更，明确应用到草稿，沿用撤销/重做/保存版本。按字面匹配，不解释正则；只改当前模式下的字幕文本，不改配音、脚本或已有媒体文件。

## 阶段二扩展：构图、基础转场和封面

- `metadata.edit.framing` 可分别保存 `9:16`、`16:9` 的 `{fit, crop_x, crop_y}`。所选画幅缺省的字段回退到原根级设置，再回退到 cover/0.5/0.5；不改写旧项目默认值。自定义输出尺寸不属于这两种比例时继续使用原根级设置。
- 构图是人工指定裁剪区域，非自动主体识别或跟踪。每种画幅可独立使用九宫格位置、X/Y 滑杆、重置；复制到另一画幅必须显式操作。contain 忽略坐标，居中留边。
- `metadata.edit.transition` 为 `{kind: "cut"|"fade_black", duration_seconds: 0.05..1}`，缺省直接切换，淡黑单侧缺省 0.3 秒。设置属于本镜头到下一镜头的边界，最后一镜头无出场转场。
- 淡黑不重叠镜头，不改变总时长，不裁剪或交叉混合配音。前镜头结尾淡出、后镜头开头淡入，已烧录字幕随画面一起淡化；单侧时长最多相邻较短镜头的一半，必要时缩短并报告警告。最终结果的 `visual_processing` 记录实际构图和淡化时长。
- 转场只在正式成片中呈现，素材预览仍是选段与构图/字幕预览。构图和转场沿用草稿、保存版本与恢复流程，不重新生成配音。
- `POST /projects/{id}/covers/render` 接受 `{activity_id, source_video_path, settings}`，返回 `covers.render` 后台任务。来源必须是当前活动已登记、仍存在且位于项目内的成片，包括历史导出。封面任务沿用活动隔离、取消、并发修改和持久化保护。
- 封面设置：`time_seconds` 非负且早于视频结束；`title` 最多 80 字和 3 个显式行；`position` 为 top/center/bottom；`font_size` 16..96（720p 基准）；`color` 为 #RRGGBB；`background` 为布尔值。空标题只提取画面，不要求字幕字体。
- 从应用生成的恒定帧率成片提取 `floor(time_seconds * fps)` 帧，记录实际帧序号和时间。先在临时目录生成、探测验证 PNG，再发布到唯一文件名；不覆盖成片或已有封面，不重渲染整条视频。
- 活动 `metadata.covers` 保留最近 30 条记录；旧图片文件不自动删除。记录包括 `image_path`、`source_video_path`、设置、实际帧时间和尺寸；路径遵循现有项目相对路径保存/重定位机制。封面不内嵌 MP4，也不自动发布到平台。
- 界面按当前选中的成片版本显示封面；选帧视频仅显示原成片画面，标题效果以生成后 PNG 为准。未成功生成时不把旧封面标记为新结果，设置仍保留。
