# 阶段二配音对齐字幕验收

日期：2026-10-24。结论：配音生成后会自动对齐，字幕时间从估算变成实测，偏差见下文。对齐环境不可用时回退估算，并写明原因。本轮 AI API 调用为 0。

## 本轮范围

- 配音生成或单句重新生成后，每段配音都用已知文案做强制对齐（做法和依据见 [WhisperX中文对齐实测](WhisperX中文对齐实测.md)）：
  - 对齐前把数字换成中文读法，时间再映射回原文；
  - 按句读切成分句，前后连续不留空档；
  - 首尾是英文的分句，边界吸附到 FFmpeg 检测出的最近静音（0.4 秒内），吸附不上时提示复核。
- 配音页新增“按配音对齐字幕”。它用现有配音重新取时间，不重新生成配音，适合老工程。
- 结果保存在配音片段上（`metadata.subtitle_alignment`，相对配音起点）。字幕仍是默认状态的镜头会自动改成“逐条定时”，排在配音前留白之后，来源标为“实测”或“估算”。这次修改记一条编辑历史“按配音对齐字幕”，可以撤销。
- 编辑器里：
  - 实测字幕显示“实测时间 · 按配音对齐”，导出时不再提示“估算待校准”；
  - 修改配音前留白后，可以点“按配音分句”重新套用；
  - 对齐提示（英文边界需复核、估算原因）列在字幕时间下方。

## 边界与保护

- 手动改过字幕文字，或手动定过时间的分句，不会被覆盖。配音文案和镜头文案不一致（配音已过期）时，也不套用。
- 对齐在单独的进程里运行，用单独的 Python 环境，主程序不装 PyTorch。以下情况都回退为按字数估算的分句，标为“估算”并写明原因：
  - 没配置对齐环境；
  - 找不到对齐环境或模型（例如外接盘没插）；
  - 对齐进程出错、超时或返回内容对不上。
- 对齐时把配音的存储时长更新为 ffprobe 实测值。TTS 返回的时长可能偏短，渲染本来就用实测值，更新后最后一条字幕不会被截掉。
- 镜头设了手动时长且短于配音时（这样的工程本来就导不出来），不更新它的时长和字幕，并提示“手动时长短于配音”。其他镜头照常更新。
- 对齐失败不会让配音任务失败，新生成的配音始终保留。

## 配置

在 App 配置文件里写这三项，或用同名环境变量：

| 配置项 | 环境变量 | 本机取值 |
| --- | --- | --- |
| `aligner_python` | `MIMO_ALIGNER_PYTHON` | 装了 WhisperX 的独立环境，在系统盘 |
| `align_model_dir` | `MIMO_ALIGN_MODEL_DIR` | 外接盘 `_dev/models/wav2vec2-large-xlsr-53-chinese-zh-cn` |
| `align_nltk_data` | `MIMO_ALIGN_NLTK_DATA` | 外接盘 `_dev/models/nltk_data` |

对齐进程 `tools/align_worker.py` 只依赖 WhisperX，不导入本仓库的模块。一次调用处理多段配音，模型只加载一次。

## 实战证据

**真实 MiMo 配音**：取一个本机工程的副本（10 个镜头、10 段配音、共 24 秒）跑“按配音对齐字幕”。原工程没有改动。

- 用时 4.8 秒。10 个镜头的字幕都从“整镜头”改成了实测分句，没有提示。编辑历史多了一条“按配音对齐字幕”。
- 真实时间用能量检测得出，误差单位为毫秒，格式“中位 / 最大”：

| | 开头 | 结尾 | 停顿后的分句开始（4 处） |
| --- | --- | --- | --- |
| 实测 | 50 / 120 | 30 / 340 | 75 / 90 |
| 估算（原做法） | 45 / 110 | 60 / 380 | 105 / 130 |

这批配音每段只有 1–3 秒、1–3 个分句，按字数估算本来就不太离谱，所以差别不大。

**多分句的长句**：34 个小句的合成测试集，每个小句的起止都精确已知，走的是和 App 相同的流程。其中 2 段因为顿号也被切成分句、条数和基准对不上，两种做法都没计入。

| | 分句开始（18 处） | 整段开头和结尾（28 处） |
| --- | --- | --- |
| 实测 | 中位 50，90% 在 90 以内，最大 110 | 中位 20，90% 在 60 以内，最大 280 |
| 估算 | 中位 80，90% 在 350 以内，最大 510 | 这组音频首尾没有静音，估算按定义为 0，不可比 |

这一组里首尾是英文的分句都吸附到了静音，没有提示需复核。

**界面**：在开发版 App 里打开上述副本（后端单独指向验收目录，不影响正式工程列表），看第 1 个镜头：
- 字幕时间模式已是“逐条定时”，显示“实测时间 · 按配音对齐”，“按配音分句”按钮可用；
- 两条分句为 0.1–1.84 秒和 1.84–2.2 秒，首尾相接；
- 实际配音显示 2.30 秒，存储值已从 TTS 返回的 2.0 秒更新为实测值。

退出 App 后没有残留进程。
