# 第二阶段第一批：素材片段与候选选择

日期：2026-10-07。结论：本批片段功能已验证，第二阶段仍在实施，完整六阶段目标未完成。

## 已实现

- 素材库对选中的已打标视频建立片段索引；分析窗口可选 2-30 秒，每条视频最多 8 个窗口，每个窗口抽取 3 帧。
- 时间范围由本地视频信息确定，模型只描述画面，不能改写时间或媒体路径。
- 片段记录具体画面、可见标签、不确定项、原字幕风险和缩略图。长视频未覆盖的时间范围会明确提示。
- 分镜工作台根据当前草稿、实际目标时长及额外检索词查询候选。显示匹配项、缺失项、可用时长与不足时长，不直接套用整条素材的标签。
- 预览候选后，对存在风险的候选必须显式勾选确认才能采用；只更新素材和取段范围，不更改配音、字幕、裁剪或短素材处理策略。
- 采用结果接入现有草稿撤销/重做、保存、重开和已保存版本恢复。
- 素材指纹变化或文件缺失时拒绝使用旧分析；项目内媒体路径可迁移。失败、取消或活动冲突不会覆盖旧项目状态。
- 模型返回不完整时最多拆为逐窗口各重试一次；仍然失败就整体拒绝保存。网络错误不会触发该拆分重试。

## 质量边界与下一批

- 这是抽样时间窗口索引，不是逐帧理解或自动镜头边界检测。窗口内可能有场景切换，3 帧不能证明连续动作；长视频最多 8 个窗口可能遗漏内容。
- 候选排序使用保守文本匹配，不是经过校准的语义置信度；完整长句要求可能无法命中。模型自评不作为准确率承诺。
- 本批增加人工确认的候选选择；没有替换原自动合成计划的整条素材匹配逻辑。
- 本次降低的是选段不足导致的人工补末帧，并未证明所有画面都与旁白匹配。原素材烧录字幕仍在，测试字幕与重复旁白也保留，样片不是可直接商用成片。
- 下一批继续处理音量/停顿、背景音乐及人声压低音乐、字幕时间对应/品牌词纠错，再推进主体裁剪、转场、封面和模板。
- 第二阶段最终仍需用户观看同素材前后版本，判断画面、字幕、声音与节奏，并记录需要手改的地方；目前该验收为待确认。
