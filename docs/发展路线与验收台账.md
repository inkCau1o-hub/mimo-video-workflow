# MiMo Workflow 发展路线与验收台账

目标：六个阶段、两次交付。阶段一至四形成个人生产版，阶段五至六形成可分发试用版。
完整目标保持有效；单个阶段通过不代表整体完成。每个阶段先测试、再用真实视频验收，只有证据齐备才标记通过。

## 阶段一：可控编辑（功能验收通过，2026-10-07）

- 素材片段：起止时间、选段预览、替换、素材不足处理。
- 镜头编辑：顺序、删除、复制、裁剪、配音与画面时长。
- 独立字幕：正文、断句、位置、字号、颜色和背景；字幕修改不重配音。
- 恢复：草稿撤销重做、持久保存版本、历史恢复、保留音频与成片。
- 门槛：真实素材完成 30-60 秒视频，实际修改画面/字幕/旁白；撤销、保存重开、搬迁和导出一致。
- 当前证据：`阶段一验收报告.md`。176 项 Python 测试、73 项前端测试、两项冒烟检查及构建通过；真实 API 配音、39.5 秒横竖屏导出、界面编辑/恢复/下载、中文空格目录搬迁已验证。
- 本阶段仅确认编辑功能，不代表成片审美或日常生产质量达标。下一阶段先处理素材固有字幕、选段不足导致停顿和画面与旁白的匹配问题。

## 阶段二：成片质量（实施中，片段、声音、字幕与留白功能已验证，2026-10-07）

- 片段级内容与时间范围索引，推荐候选片段。
- 推荐理由、低匹配提示、缺素材提示与人工确认。
- 音量、停顿、音乐、人声压低音乐、字幕时间对应和品牌词纠错。
- 横竖屏主体裁剪、基础转场、封面；产品介绍/卖点展示/使用场景模板。
- 门槛：同素材生成改进前后版本，由用户确认画面、字幕、声音与节奏，记录仍需手改的地方。
- 外部依赖：审美与内容质量需要用户判断，不用机器成功导出替代。
- 当前证据：`阶段二片段功能验收.md`。已完成抽样片段索引、候选理由/缺素材提示、预览确认采用及编辑历史衔接；真实两段素材形成 5 个候选窗口，同配音完成 39.5 秒横竖屏对比导出和搬迁验证。
- 声音证据：`阶段二声音功能验收.md`。已完成配音响度统一、音量调节、音乐导入/循环/淡入淡出、人声压低音乐、保存与导出版本记录；220 项 Python 测试、93 项前端测试通过，真实素材完成 39.5 秒横竖屏混音导出、中文空格目录搬迁及界面播放验证。
- 字幕与留白证据：`阶段二字幕与节奏功能验收.md`。已完成逐条字幕时间编辑、配音期间字幕、预览时间切换、字幕批量字面纠词、配音前后留白、保存/恢复；234 项 Python 测试、105 项前端测试通过。保留完整配音的对比样片由 39.5 秒缩短为 24.667 秒，横竖屏及中文空格目录搬迁通过。
- 尚未完成：语音内部停顿处理、语音级自动精确对齐、自动品牌词识别、主体裁剪改进、转场/封面/模板，以及用户质量验收。当前纠词为人工指定原词与正确词，分句时间草稿为估算，不能把单项功能验证标记为整个阶段通过。

## 阶段三：批量提效（未开始）

- 产品资料/素材/声音/模板复用与项目复制。
- 转写、分析、配音缓存；输入或设置变化后准确失效。
- 多任务队列、取消、失败步骤重试、重启后检查产物再继续。
- 不同开场/时长/画幅版本；用量记录、费用估算与预算限制，估算的不确定性明确显示。
- 门槛：同一产品连续制作多个版本，记录实际重复操作/调用减少及失败隔离证据。

## 阶段四：自用验证（未开始）

- 至少 10 条真实作品，覆盖 30/60 秒、不同素材、横竖屏、多轮修改。
- 逐条记录人工操作/等待时间、实际或估算费用、返工次数、是否采用；没有测量的数据留空，不伪造。
- 演练断网、接口错误、重启、磁盘不足、缺失文件、目录搬迁。
- 修复高频问题，补齐备份恢复，控制新增功能。
- 门槛：用户日常核心流程不再依赖临时改代码或修文件；用户确认后交付个人生产版。

## 阶段五：安装交付（未开始）

- Windows 安装与启动，依赖管理；程序/数据/设置分离。
- 首次密钥和目录配置、连接检查、安全保存，不导出密钥。
- 版本检查、升级前备份、升级失败恢复、项目搬迁与重新定位素材。
- 普通界面与调试信息分离，示例项目、错误原因与恢复入口。
- 门槛：干净 Windows 设备完成安装、配置、制作、导出和升级；macOS 单独实机验收。
- 外部依赖：新 Windows 环境和 macOS 设备可用性需真实验证，不以当前开发机代替。

## 阶段六：小范围试用（未开始）

- 3-5 位目标使用者独立使用自己的素材完成任务。
- 收集停顿点、误解、返工，修复共同问题。
- 用户确认后导出脱敏诊断，不默认上传素材/密钥/完整项目。
- 支持系统/格式/限制/恢复说明、版本说明和问题处理清单。
- 门槛：真实试用者能独立完成核心流程，关键问题关闭后交付可分发试用版。
- 外部依赖：用户安排试用者与授权联系；不虚构试用记录、不擅自联系第三方。

## 全程约束

- 每项改动测试，旧项目兼容、可迁移路径、密钥不泄露、macOS 入口保留。
- 任务深度最多当前会话-分支-分支，本轮只使用同级分支。
- 不提前建设账号/团队/云端/自动发布系统。
- 记录实际耗时和问题后再估算下一阶段工期。
- 原始测试素材和既有项目不覆盖，验收项目放在 `output/acceptance` 的独立目录。
